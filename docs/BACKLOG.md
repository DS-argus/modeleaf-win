# 향후 개발 백로그

아래 항목은 소유자가 기록한 향후 작업 영역이며, 현재 구현 승인이 아니다. 구현 전 각 항목은 자체 Issue 계약, worktree, macOS v0.10.0 소스/테스트 매핑, Windows 차이, 승인 증빙, 그리고 승인을 갖춰야 한다.
## 전면 UI 정비

이 항목은 탭과 상태 표시줄을 분리 구현하지 않는다. 먼저 `docs/reference/DESIGN.md`를 기준으로 현재 UI와의 시각·상호작용 차이(정보 밀도, 색상 토큰, 여백, 계층, 포커스/선택 상태, 오버레이)를 검토하고 소유자와 범위 및 Windows 차이를 논의한다. 그 결과가 확정된 뒤에 아래 작업을 하나의 조정된 UI 변경으로 진행한다.

- 전반적인 디자인 감성을 `docs/reference/DESIGN.md`와 통일한다. macOS 좌표나 컨트롤을 그대로 복제하지 않고, native Windows title bar와 플랫폼 적응 원칙을 유지한다.
- 탭 디자인을 `docs/reference/tab-reference.png`에 맞춰 수정한다.
- 하단 상태 표시줄의 형태와 정보 계층을 `docs/reference/status-reference.jpg`에 맞춰 수정하고, 앱 빌드/버전 권한을 사용한 설치된 Modeleaf 버전을 함께 표시한다. 버전은 간결하고 접근 가능하게 유지하며, 패키지된 CLI/Scoop/NSIS 빌드에서 정확해야 하고 업데이트 가능 여부와 분리한다.
- 테마 변경은 `appLocalDataDir()/state.json`에 저장되어 다음 실행에서도 유지되어야 한다. 현재처럼 재실행 시 초기화되는 결함을 수정하고, 저장·복원 실패를 성공으로 표시하지 않으며 테마 상태와 접근성/강제 색상 동작을 함께 검증한다.

현재 UI, 참조 이미지, 최소 창 크기, 테마, 키보드 포커스, 강제 색상 및 텍스트 배율에서의 차이를 명시적으로 검토한다. 시각 참고 자료는 구현 승인이 아니며, 최종 동작과 접근성 기준은 Issue 계약에서 확정한다.

## 리더 보기·입력 및 Tabs 메뉴 단순화

- 초기 PDF 열기 시 기본 표시를 `Fit Page`로 설정한다. 최초 viewport 확정, 문서별 초기화, 창 크기 변경, 렌더 취소/세대 경계 및 기존 `Fit Page`/`Fit Width` 액션과의 일관성을 검증한다.
- 비밀번호로 보호된 PDF를 열 때 비밀번호 입력 오버레이를 제공한다. 잘못된 비밀번호 재시도와 취소를 구분하고, 비밀번호를 상태·설정·최근 파일·로그에 저장하거나 노출하지 않으며, 문서 세션 종료 시 메모리에서 폐기한다.
- `n`, `p`, `d`, `u`를 빠르게 연속 입력하거나 키를 지속해서 누르는 상황의 회귀 테스트를 추가한다. 단위 테스트뿐 아니라 패키지된 WebView2에서 실제 반복 키 입력으로 목적지 landing, stale 처리, 경계 도달, 렌더 취소, viewport 동기화 및 원래 위치 복구가 거짓 실패 메시지 없이 일관되게 동작하는지 검증한다.
- PDF를 연 상태에서 `Ctrl` + 마우스 휠로 확대/축소한다. 기존 확대율 범위, 렌더 취소/세대 경계, 키보드 확대/축소 및 포커스 동작과 충돌하지 않도록 정의하고 검증한다.
- 메뉴바의 **Tabs** 메뉴는 `Previous Tab`과 `Next Tab`만 표시하도록 수정한다. 탭 `1`~`9` 직접 선택 항목은 제거하며, 액션 레지스트리·기본 키맵·메뉴/팔레트/도움말 투영에 남은 해당 항목도 함께 정리한다.

## Modeleaf CLI

로컬 PDF 열기, 설치된 버전 표시, `modeleaf update`와 같은 업데이트 관련 명령을 위한 Windows `modeleaf` 명령 표면을 추가한다. 먼저 명령 문법, 종료 코드, stdout/stderr, 단일 인스턴스 라우팅, 현재/새 창 동작, 설치 소유권 및 업데이트 의미를 정의한다. argv, 파일 시스템, 네트워크 및 설치 권한은 Rust가 소유한다.

## 업데이트 가능 여부 및 릴리스 세부 정보

지원되는 최신 버전이 있으면 간결한 푸터 알림을 표시한다.

```text
x.y.z available — modeleaf update (detail [U])
```

`U`는 업데이트 세부 정보 화면을 연다. `Shift+U`는 최신 릴리스 하이라이트를 담은 간결한 오버레이/팝업을 연다. 둘 다 알림 전용으로 유지한다. 백그라운드 다운로드, 자동 업데이트, 강제 재시작 또는 자동 설치를 추가하지 않는다. 릴리스 노트의 출처, 정제, 캐싱, 오프라인/잘못된 형식/사전 릴리스 동작, 그리고 포커스/Escape/접근성 동작을 정의한다.

## 링크 힌트, 대상 표시기 및 히스토리 키

다음 항목을 하나의 조정된 리더 도메인으로 재도입한다.

- `f` 키보드 링크 힌트 및 활성화
- 링크 이동 성공 후 대상 표시기
- `Ctrl+o` 히스토리 뒤로 및 `Ctrl+i` 히스토리 앞으로

새 Issue가 이 작업을 명시적으로 재승인하기 전까지 현재 퇴역 링크 문서는 이력으로만 유지한다. 일반 마우스 링크, 외부 링크 권한 부여, 불투명 세션, 표준 PDF 페이지 공간 히스토리, 취소/리소스 경계, 읽기 전용 PDF 및 다중 창 소유권을 보존한다.

## 보호된 Scoop 버킷 승격 자동화

태그 워크플로가 정확히 검토된 GitHub Release를 게시한 뒤 공개 자산을 다시 다운로드하고 검증하여 Scoop 매니페스트를 생성하고, 별도 버킷 저장소 PR을 자동으로 생성한다. 버킷의 main 브랜치에 직접 push하지 않는다.

`DS-argus/scoop-bucket`에 대해 `contents: write` 및 `pull-requests: write`로 제한된 저장소 범위 세분화 PAT 또는 GitHub App 토큰을 사용한다. 정확한 소스/ZIP/해시/영수증 검증, 공개 다운로드 검증 및 사람의 검토/병합 게이트를 보존한다. 이 기능으로 Modeleaf에 자체 업데이트 동작을 추가해서는 안 된다.
